# ML Fundamentals 2025
### Individual Assignment for Machine Learning Foundations

1. **Project Description**  
   This project is a submission for Assignment 1 in the ML Fundamentals 2025 course. It includes tasks related to data preprocessing, feature engineering, and machine learning model evaluation using the Titanic dataset.

2. **How to Use**  
   Follow these steps to use the project:

   - **Clone this repository**:  
     ```bash
     git@github.com:Julia047/ML-fundamentals-2025.git
     ```
   - **Navigate to the project directory**:  
     ```bash
     cd ML-fundamentals-2025
     ```
   - **Open the Jupyter Notebook**:  
     ```bash
     jupyter notebook assignment_1_Tianyang_Chen.ipynb
     ```
3. **Required Packages**
     Please see requirements.txt
